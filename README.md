# 灵感笔记 (Inspiration Notes)

一个现代化的笔记记录应用，采用深色主题设计，使用纯 HTML + CSS + JavaScript 实现，数据存储在 Local Storage 中。

## 功能特性

- 📝 发布文字笔记
- 🖼️ 发布带图片的笔记（图片转为 Base64 存储）
- 📚 查看所有已发布的笔记
- 🗑️ 删除已发布的笔记
- 💾 数据持久化（Local Storage）
- 🔍 搜索笔记功能（待实现）
- 📱 响应式设计

## 技术栈

- HTML5
- CSS3 (渐变、动画、Grid 布局)
- JavaScript (ES6+)
- Local Storage

## 使用说明

1. 打开 `index.html` 文件
2. 在编辑器中输入文字内容
3. 可选择上传图片
4. 点击"发布笔记"按钮
5. 内容将显示在笔记列表中
6. 点击"删除"按钮可删除笔记

- 侧边栏导航
- 响应式网格布局

## 注意事项

- 图片使用 Base64 编码存储，受 Local Storage 大小限制（约 5-10MB）
- 建议不要上传过大的图片
- 数据仅存储在本地浏览器中，清除浏览器数据会丢失
